# 新视觉原型

静态 HTML 原型，不参与构建。用任意静态服务器打开，例如在本目录运行 `python3 -m http.server`。

| 目录 | 内容 |
|---|---|
| `site/` | 网站的完整交互原型。入口 `index.html`，交互说明在 `ux.html`。中英文在导航里切换，也可以在地址后加 `?lang=zh` 或 `?lang=en`。右下角的「原型控制」用来切换登录、客户端、套餐等模拟状态 |
| `client-app/` | 桌面客户端的完整交互原型。入口 `index.html`（`#/welcome` 是首次启动，`#/discover` 直接进发现），交互说明在 `ux.html`，从代码整理的功能清单在 `INVENTORY.md`。右下角的「原型控制」可以切换登录、套餐、检测到的 agent、示例项目、窗口样式，以及模拟网页发来的安装链接 |
| `../tiles/tiles.html` | 三个视觉方向的样片。选定的是 C（光谱） |

文案集中在 `site/i18n.js`，示例数据 `site/data.js` 取自测试环境目录的真实条目，价格在 `site/plans.js`。

原型已在 #167 合入 main，原 `design/redesign-prototype` 分支已删除。网站和客户端的 C 光谱改版、收藏、网页「已安装」状态、项目级技能与 MCP 已落地；应用的当前行为以 main 的源码、各自的 DESIGN.md 和产品文档为准。用量页的数字是示例数据。

2026-11-18 文档校正：备份与跨设备同步已实现，入口在客户端「设置 → 备份与同步」，使用用户自己的 Git 仓库，不经过 Agent Store 服务器；网站账户页没有设备同步标签。参见 [备份与同步说明](../../backup-sync.md)。静态原型没有模拟完整备份流程，客户端设置中的说明指向该文档。

这些静态页面保留了早期交互模拟，不是当前应用的完整镜像。`client-app/INVENTORY.md` 和两份 `ux.html` 中未注明更新的盘点、提案与待定项是当时的设计记录，不能据此断言 main 尚未实现相应功能；独立结账页等模拟也不代表生产站点的路由。
